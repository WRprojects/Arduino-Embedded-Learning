# Potentiometer PWM LED

## Project Goal
Read input from a potentiometer using aruduino microcontroller.
Convert the raw analog input from a 0-1023 to 0-255 range for pulse width modulation with the LED. Use the value for the output signal using PWM pin on the arduino to control the brightness of the LED.

## Hardware Used
- 1 potentiometer
- 1 220 ohm resistor
- 1 red LED
- 1 Arduino UNO R4 wifi

## Problems
The main problem ran into was arduino IDE not uploading the program. I fixed this by selecting the right board and port configuration.

## Things I Learned
I learned waht pulse with modultaion was and how it worked.

I learned how to measure an analog voltage and convert it to a numerical value to use for controling a PWM digital output.

I learned some useful things about C++ programing, such as how to round a floating value into an integer value with out just casting from int to float.
